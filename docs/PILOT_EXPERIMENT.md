## 准备命令与实际检查

在仓库根目录使用PowerShell 7：

```powershell
# 仅导出本地快照，不连接模型服务
.\.venv\Scripts\python.exe -B -m scripts.prepare_pilot

# 将快照来源导入本地Dify并保存三组草案，不执行生成
.\.venv\Scripts\python.exe -B -m scripts.prepare_pilot --index
```

默认输出work/pilot-dev-v1，已有快照不被重新生成或覆盖。--index可继续未完成的导入；不重传同名文档，也不覆盖已保存的草案。此脚本没有回答模型调用或应用发布入口。

实际保存并读回了三组草案，确认模型参数、共同任务、上下文开关和重试设置。现有10题分别在G1/G2做纯本地检索，共20次，每次返回4条记录；这只证明检索能返回内容，**不等于20题正确或证据完全覆盖**。没有生成或评分。

上段为付费调用前的纯本地预检。用户随后授权批量并要求增加余量，首次生成前将三组输出上限从1024统一更新为2048，读回核对后执行30次实际生成；没有追加调用或自动评分。获得对应人类授权后执行的命令如下，不是对后续任意批次的许可：

```powershell
.\.venv\Scripts\python.exe -B -m scripts.run_pilot --authorize-paid-calls
```

run_pilot只运行现有10题×3组；每次在请求前写入状态，已有成功记录不重新发送，已有失败/不明确记录直接停止，不自动补跑。生成后的answers.jsonl用于真实回答留存，ratings.jsonl是人工评分工作副本，既有评分文件不被覆盖。缺少授权开关时在网络请求前退出。

私有运行输入与检索输出：

- work/pilot-dev-v1/config.json：本轮实际2048上限及授权记录，chat_calls_authorized=true。
- work/pilot-dev-v1/requests.jsonl：本轮执行的30条请求清单，无参考答案。
- work/pilot-dev-v1/questions.json：已复核的开发题/参考要点快照，仅供评分，不导入知识库。
- work/pilot-dev-v1/sources/G1与sources/G2：两组独立的来源快照。
- work/pilot-dev-v1/state.json：本地实验应用和知识库标识、限定范围API Key，含凭据，不可公开。
- work/pilot-dev-v1/retrieval-precheck.json：实际20次本地检索返回，含原书片段，不公开或纳入知识库。
