# 回答引用与证据边界修复

日期：2026-10-27。两项修复已实现并同步到独立Dify交付草案。完成离线回归和真实Code节点回放，未新增模型生成或联网搜索。

## 1. 联网引用对应网址

回答链路改为`LLM → finalize（Code）→ answer`，不再直接输出LLM文本。finalize从本轮实际传给模型的网页证据中读取编号与URL，在最终回答末尾补充“来源链接”。

- 只列出答案引用的编号，不把未引用的搜索结果混入出处。
- 同一编号只生成一条映射；再次处理同一结果不重复追加列表。
- 仅使用本轮返回且含正文片段的有效网页URL。未知编号不会被猜测配对，而是明确说明无法核验。
- 新节点不访问网络，也不增加模型调用。来源链接可追溯不等于每项结论已被来源支持，内容判断仍需保留。
- 最终回答引用finalize输出，避免把未经整理的LLM文本先当成最终回答展示。

## 2. 证据不足时的措辞

系统提示明确区分“未找到支持证据”和“已有反证”：资料未提及、搜索无结果或个别案例不能直接推出一项规定不存在。只有来源明确反驳命题且适用范围一致时，才给出确定否定并说明依据。

后续提示词已按用户要求收敛为通用原则，并采用自然中文解释、括号展示专业术语的表达方式；不再在系统提示中逐项列举特定业务案例。上述证据边界原则及下述输出整理规则保留。

此外，输出节点处理一种已复现的句式：回答先以“不是/没有/不需要”等作确定结论，紧接着仅以“现有资料没有规定/证据不足”等解释时，将首句改为“现有资料不足以支持这一说法”。后续内容保留；有明确反证的否定及已经限定范围的回答不被替换。

这是针对已发现问题的有限规则，不是通用语义判定器。新增模型生成能否持续遵守规则，仍需在另行授权的小批真实回归中验证。
