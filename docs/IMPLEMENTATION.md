## P1：小批资料与选题预实验

按已确认的 Dify / PaddleOCR / BGE-M3 / 用户可配置回答模型路线推进；本地默认DeepSeek Flash系列API（deepseek-flash），凭据和服务参数由用户自行配置，同一轮实验固定配置。不把默认模型选择当作外发或费用授权。

1. 在本地处理核心页，不将原书发到第三方平台。
2. 对日文文字、数字/汉字、图示关系和页码做校订，保留原文与中文解释。
3. 人工复核 pilot.json 的参考要点；草案未复核前不作为最终真值。
4. 确认可调用的模型、材料外发范围及费用授权，冻结模型配置。
5. 先测 G0 无检索，再测小样本检索回答；开发题可以调试，但不得成为最终评测结果。

三组开发生成及用户要求的AI评审已完成：30份回答，2048输出上限，无截断/补跑；AI总分G0/G1/G2为11/17/19（各满分20）。发现book-013与DEV-08参考的絵/线条偏差，下一步先修正并版本化资料，再设计独立题；不把本轮AI分数当作P1最终验收。分析见[PILOT_AI_REVIEW.md](PILOT_AI_REVIEW.md)，实际用量见[PILOT_RESULTS.md](PILOT_RESULTS.md)。
